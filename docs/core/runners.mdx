# Runners

`Runner` is the project word for how an environment gets started.

You do not need to worry about this page when first trying Gym Anything. It becomes important when:

- something does not start on your machine
- you want a different way to launch environments
- you need a feature that only some launch methods support

## Common Options

Gym Anything can use different launch methods, including:

- Docker
- Apptainer direct
- QEMU
- AVD
- AVF on Apple Silicon
- Local

## Easiest First Step

If you are unsure what works on your machine, run:

```bash
gym-anything doctor
```

That is the fastest way to see what is installed and what is missing.

## What Changes Between Launch Methods

Different launch methods support different things.

For example, depending on how you start the environment, support may differ for:

- caching
- recording
- save-and-restore features
- platform-specific behavior

You usually only need to care about these differences once you move beyond the first run.

## Quick Feature Table

If your question is simply "does this support caching?" or "can I use savevm here?", use this table:

| Launch method | Caching | `use_savevm` | Live recording |
|---|---|---|---|
| Docker | Yes | No | Yes |
| Apptainer direct | No | No | No |
| QEMU | Yes | Yes | No |
| AVD | Yes | No | No |
| AVF | No | No | No |
| Local | No | No | No |

This is the current behavior in the codebase.
