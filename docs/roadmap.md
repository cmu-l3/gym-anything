# Roadmap

This is a practical roadmap, not a promise that all items already exist.

## Near-Term Priorities

- tighten package dependency metadata so installation matches real usage
- reduce the gap between benchmark JSON conventions and loaded dataclasses
- make runner support for fields more explicit and more uniform
- stabilize remote-service behavior relative to local `GymAnythingEnv`
- improve test coverage around loaders, verifiers, and runner selection

## Medium-Term Priorities

- improve artifact schemas and step/summary consistency
- reduce hardcoded behavior in the baseline harnesses

## Long-Term Priorities

- cleaner packaging and versioned public API boundaries
- stronger remote orchestration and metrics
- better runner capability discovery
- more systematic benchmark curation tooling
