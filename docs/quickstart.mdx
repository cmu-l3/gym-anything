# Quickstart

This page is the fastest path from clone to first successful run.

## 1. Install The Runtime

```bash
pip install -e .[all]
```

## 2. Add Optional Secrets

If you use online model providers:

```bash
cp .env.example .env
```

Then fill in the keys you need.

## 3. Check Your Setup

```bash
gym-anything doctor
```

This command tells you what is installed, what is missing, and interactively asks your permissions to install the missing ones (eg, docker).

## 4. Load An Environment

```python
from gym_anything import from_config

env = from_config(
    "benchmarks/cua_world/environments/zotero_env",
    task_id="create_saved_search",
)

obs = env.reset(seed=42)
obs, reward, done, info = env.step([], mark_done=True)
env.close()
```

## 5. Run An Example Agent

```bash
python -m agents.evaluation.run_single \
  --env_dir benchmarks/cua_world/environments/zotero_env \
  --task create_saved_search \
  --agent ClaudeAgent \
  --agent_args '{"model":"claude-3-7-sonnet"}'
```
