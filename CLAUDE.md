# Compact instructions

When compacting, always preserve the following:

1. **User instructions and task goals** - The full description of what the user asked to accomplish, including any multi-step plans or acceptance criteria
2. **Current task status** - What has been completed, what is in progress, and what remains to be done
3. **Interactive testing requirements** - Any instructions about testing, validation steps, or interactive checks that still need to happen
4. **Files modified** - Complete list of files created, edited, or deleted during this session, with a brief note on what changed in each
5. **Key decisions and context** - Architectural choices, user preferences, and constraints that affect remaining work
6. **Unresolved errors or blockers** - Any issues encountered that still need to be addressed
