# Business Impact Analysis

## Task Description
Transform raw stakeholder interview notes into a formal Business Impact Analysis (BIA) document following ISO 22301 standards.

## Occupation Context
Business continuity planner at a financial services firm.

## Difficulty: Very Hard

## Challenges
- Extract structured data (RTO, RPO, MTPD, dependencies) from unstructured interview prose
- Create a Risk Assessment Matrix table (5x5 likelihood vs. impact grid)
- Create a Recovery Priority table with process-specific recovery metrics
- Create a RACI responsibility assignment matrix
- Apply proper BIA document heading hierarchy
- Synthesize interview notes into an executive summary
- Format all tables professionally
- 6 critical business processes must be represented

## Data Source
ISO 22301 Business Continuity standard and FEMA BIA template structure.

## Verification
- BIA section headings with proper styles (python-docx)
- Heading hierarchy depth
- Recovery Priority table with RTO/RPO data
- Risk Assessment Matrix detection
- RACI matrix detection
- Table header formatting
- Executive summary presence and position
- Process data completeness (6 processes)
- VLM visual verification
