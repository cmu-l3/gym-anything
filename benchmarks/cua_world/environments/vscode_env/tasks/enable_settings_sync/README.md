# VSCode Settings Sync Setup Task (`enable_settings_sync@1`)

**Difficulty**: 🟡 Medium  
**Skills**: Settings navigation, Cloud sync configuration, Command Palette  
**Duration**: 180 seconds  
**Steps**: ~20

## Objective

Enable VSCode's Settings Sync feature to synchronize settings, keybindings, extensions, and snippets across multiple machines. Configure sync preferences through the Settings Sync dialog.

## Expected Workflow

1. Open Command Palette (Ctrl+Shift+P)
2. Search for "Settings Sync: Turn On"
3. Open Settings Sync configuration dialog
4. Select sync preferences (Settings, Keybindings, Extensions, Snippets, UI State)
5. Initiate sync setup process

## Real-World Context

A developer wants to maintain consistent VSCode configuration across their work laptop and home desktop. They need to enable Settings Sync to keep extensions, keybindings, and preferences synchronized automatically.

## Verification

Checks for:
1. Settings Sync configuration present in user settings
2. Sync preferences enabled in configuration files
3. Attempt to enable sync recorded in storage
4. Sync-related settings properly configured

**Pass Threshold**: 80% (4/5 criteria)
