# Sync Forked Repository Task

**Difficulty**: 🟡 Medium  
**Skills**: Git remote management, fetch, merge, rebase, open-source workflow  
**Duration**: 300 seconds  
**Steps**: ~50

## Objective

Configure upstream remote and synchronize a forked repository with the latest changes from the original project. This simulates the common open-source contribution workflow where your fork becomes outdated and needs to be synced.

## Scenario

You forked the `fastcache` Python library 2 weeks ago and have been working on a feature branch. The upstream repository has received 5 new commits with bug fixes you need. Your feature branch is based on an outdated main branch.
