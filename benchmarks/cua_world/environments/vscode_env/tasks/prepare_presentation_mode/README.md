# Prepare Presentation Mode Task

**Difficulty**: 🟡 Medium  
**Skills**: Settings configuration, UI customization, workspace management  
**Duration**: 240 seconds  
**Steps**: ~50

## Objective

Transform a typical working VSCode environment into a presentation-ready configuration suitable for live coding demos, screen sharing, or technical talks. The workspace needs to be readable, professional, and distraction-free.

## Scenario

You're a developer who has been coding all morning with your personal productivity setup (small fonts, many panels, cluttered workspace). In 5 minutes, you need to join a video call and do a live coding demo for stakeholders. Your screen needs to be readable, professional, and distraction-free.

## Expected Workflow

1. Open Settings (Ctrl+, or File → Preferences → Settings)
2. Increase editor font size to 18-20px
3. Increase terminal font size to 16-18px
4. Disable minimap for cleaner view
5. Disable breadcrumbs to save vertical space
6. Hide activity bar (View → Appearance → Activity Bar)
7. Close unnecessary files (keep only main.py and README.md)
8. Clear terminal history (type 'clear' or close/reopen terminal)

## Verification

Checks for:
1. Editor font size ≥ 18px
2. Terminal font size ≥ 16px
3. Minimap disabled
4. Breadcrumbs disabled
5. Activity bar hidden

**Pass Threshold**: 67% (4/6 criteria)
