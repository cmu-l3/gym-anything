## Troubleshooting

### VSCode Won't Start
- Check `/tmp/vscode_setup.log` for errors
- Ensure X11 display is running (`DISPLAY=:1`)
- Verify user permissions

### Extensions Not Working
- Check extension logs in Output panel
- Verify language runtime is installed (python, node, etc.)
- Check extension is compatible with VSCode version

### Git Operations Fail
- Verify Git is configured: `git config --list`
- Check repository is initialized: `ls -la .git`
- Ensure network access for remote operations

### IntelliSense Not Working
- Check language server is running: `ps aux | grep pylance`
- Verify workspace is opened (not just files)
- Check extension is installed and enabled
