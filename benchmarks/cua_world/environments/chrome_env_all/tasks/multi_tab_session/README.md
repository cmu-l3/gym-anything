# Chrome Multi-Tab Research Session Task (`multi_tab_session@1`)

## Overview

This task tests an agent's ability to manage multiple browser tabs in Chrome by opening several specific URLs in separate tabs and organizing a research session. The agent must use Chrome's tab management features (Ctrl+T for new tabs, address bar navigation) to open multiple web pages simultaneously, simulating a common real-world workflow for research, comparison shopping, or information gathering.

## Task Requirements

The agent must open exactly 4 tabs with the following URLs:

1. **Wikipedia** - https://en.wikipedia.org
2. **GitHub** - https://github.com
3. **Stack Overflow** - https://stackoverflow.com
4. **MDN Web Docs** - https://developer.mozilla.org
