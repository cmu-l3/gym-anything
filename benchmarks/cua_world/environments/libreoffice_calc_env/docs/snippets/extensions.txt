## Integration with Training Frameworks

This environment is designed for reinforcement learning and imitation learning:

- **Observation Space**: RGB screen captures at 1920x1080
- **Action Space**: Mouse movements, clicks, keyboard input
- **Reward Signal**: Sparse (0/1) based on verifier pass/fail, detailed score (0-100)
- **Episode Length**: Task-dependent (50-200 steps typical)

## Troubleshooting

### Calc Won't Start
- Check `/tmp/calc_ga.log` for errors
- Ensure X11 display is running (`DISPLAY=:1`)
- Verify LibreOffice installation: `libreoffice --version`

### File Parsing Errors
- Ensure file is saved in correct format (ODS/XLSX)
- Check file permissions
- Verify Python libraries installed: `pip3 list | grep odfpy`

### VNC Connection Issues
- Ensure VNC server is running on port 5952
- Check password is correct: `password`
- Verify port mapping in Docker configuration

### Formula Verification Fails
- Check formula syntax matches LibreOffice's format
- Verify cell references are correct (A1 notation)
- Ensure formulas are calculated (press Ctrl+Shift+F9 to recalculate all)

## Performance Optimization

- **Disable Animations**: Set in preferences to speed up GUI interactions
- **Reduce Autosave Frequency**: Set to 10+ minutes to avoid interruptions
- **Disable Recovery**: Turn off crash recovery for faster startup
- **Use Headless Mode**: For verification-only checks without GUI
