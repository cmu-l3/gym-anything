### Key Functions

- **`parse_ods_file(path)`**: Parse ODS file and return sheet data structure
- **`get_cell_value(sheet, row, col)`**: Extract cell value by coordinates
- **`get_cell_formula(sheet, row, col)`**: Extract formula from cell
- **`verify_chart_exists(doc, sheet_name)`**: Check if chart exists on sheet
- **`verify_conditional_format(sheet, cell_range)`**: Validate formatting rules
- **`verify_data_sorted(sheet, column, order)`**: Check sort order

### Verification Strategy

Tasks use deterministic file parsing:

1. **Setup Phase**: Create initial spreadsheet with seed data
2. **Agent Interaction**: Agent manipulates spreadsheet via GUI
3. **Export Phase**: Automated export to ODS format
4. **Verification Phase**: Parse ODS file and validate:
   - Cell values and formulas
   - Data structures (sorting, filtering)
   - Visual elements (charts, formatting)
   - Formula correctness and results

## Troubleshooting

### LibreOffice Won't Start

```bash
# Inside container
ps aux | grep soffice
pkill soffice
rm -rf /home/ga/.config/libreoffice/4/cache/
su - ga -c "DISPLAY=:1 libreoffice --calc &"
```

### VNC Connection Issues

- Verify VNC server: `ps aux | grep x11vnc`
- Check port mapping: Docker should expose 5952
- Password: `password`

### File Export Fails

- Check file permissions: `/home/ga/Documents/`
- Verify LibreOffice is responding: `wmctrl -l | grep -i calc`
- Check logs: `/tmp/libreoffice_*.log`

### Verification Errors

- Ensure export completed: Check file exists and size > 0
- Install dependencies: `pip3 install odfpy openpyxl`
- Check file format: ODS preferred over XLSX
- Validate XML structure: `unzip -l file.ods`

## Integration Notes

### File Format Support

- **ODS** (OpenDocument Spreadsheet): Native format, preferred for verification
- **XLSX** (Excel 2007+): Full compatibility for import/export
- **XLS** (Excel 97-2003): Legacy support
- **CSV**: Text-based import/export

### Python Libraries

Verification utilities use:

- **odfpy**: ODS file parsing (native LibreOffice format)
- **openpyxl**: XLSX file parsing (Excel format)
- **xml.etree.ElementTree**: XML parsing for ODS internals
- **zipfile**: ODS file extraction (ODS is zipped XML)

### GUI Automation

- **xdotool**: Keyboard/mouse simulation
- **wmctrl**: Window management
- **xclip**: Clipboard operations
