# Prepare Async Workshop Task

**Difficulty**: 🟡 Medium  
**Skills**: Multi-file project creation, VSCode configuration, pedagogical code writing, accessibility  
**Duration**: 300 seconds  
**Steps**: ~80

## Objective

Prepare a teaching-optimized VSCode workspace for a 2-hour workshop on "Understanding Async JavaScript: From Callback Hell to Async/Await" for coding bootcamp students. The workspace must include progressive examples, teaching-friendly VSCode settings, debug configuration, and work offline.

## Context

You're a senior developer volunteering at a weekend coding bootcamp. Tomorrow morning, you're teaching 15 intermediate students who find promises confusing. The venue has unreliable wifi, the projector is low-resolution, and one student is colorblind. You need to prepare tonight.
