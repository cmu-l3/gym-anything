# Executive Board Report

## Task Description
Transform raw departmental email updates into a professional quarterly board report for a mid-market manufacturing company.

## Occupation Context
Management consultant preparing quarterly board presentations.

## Difficulty: Very Hard

## Challenges
- Synthesize data from 5 different department heads' email updates
- Create an executive summary distilling key findings
- Build a financial performance table with actuals vs. budget vs. prior year
- Create a KPI dashboard table with 8+ cross-departmental metrics
- Build a strategic action matrix with prioritized recommendations
- Apply proper heading hierarchy to restructured content
- Format all tables professionally
- Judgment required to identify which data points are board-relevant

## Data Source
Fictional mid-market manufacturer based on typical industrial company quarterly reporting patterns.

## Verification
- Title formatting (centered, bold, company/quarter)
- Executive summary presence and position
- Financial performance table with budget comparisons
- KPI dashboard table with multi-department metrics
- Action/recommendations matrix table
- Heading hierarchy depth
- Table header formatting
- Content completeness (5 departments represented)
- VLM visual verification
