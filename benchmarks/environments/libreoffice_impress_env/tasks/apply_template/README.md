# Apply Template Task

**Difficulty**: 🟢 Easy  
**Skills**: Theme application, style management  
**Duration**: 120 seconds  
**Steps**: ~20

## Objective

Apply a template or theme to an existing presentation to change its visual appearance. This task tests the agent's ability to navigate the template system and apply consistent styling.

## Verification Criteria

1. ✅ **File Valid**: Presentation file is valid and readable
2. ✅ **Structure Preserved**: Original 3 slides are preserved

**Pass Threshold**: 50%

Note: Full template verification (checking master pages, styles, backgrounds) requires complex ODF parsing and may need manual inspection for complete validation.
