# Setup Ambient Background Task

**Difficulty**: 🟡 Medium  
**Skills**: Configuration management, persistent settings, UX optimization  
**Duration**: 180 seconds  
**Steps**: ~15

## Objective

Configure VLC Media Player for continuous ambient background playback by enabling infinite looping, setting appropriate volume, and minimizing interface distractions.

## Task Description

The agent must:
1. VLC launches with a 3-minute ambient nature video
2. Configure infinite loop (video repeats continuously)
3. Set volume to approximately 40% (background-appropriate level)
4. Minimize interface elements (hide controls/status bar)
5. Settings persist in VLC configuration file

## Expected Results

- VLC configured for infinite looping
- Volume set to 35-45% range
- Minimal interface settings enabled
- Configuration saved to vlcrc file

## Verification Criteria

1. ✅ **Loop Enabled**: Infinite loop/repeat setting found in config
2. ✅ **Volume Appropriate**: Audio volume in 35-45% range
3. ✅ **Interface Minimized**: At least one minimization setting active
4. ✅ **Settings Persisted**: Configuration file modified

**Pass Threshold**: 75% (3/4 criteria)

## Skills Tested

- Preferences navigation (Tools → Preferences)
- Advanced settings access (Show All)
- Loop configuration understanding
- Volume control precision
- Interface customization
- Configuration persistence

## Controls

- **Menu**: Tools → Preferences (Ctrl+P)
- **Loop**: Playback → Loop (or in Preferences)
- **Volume**: Volume slider or Ctrl+Down
- **Interface**: View menu → Status Bar, Advanced Controls

## Real-World Context

This setup is used for:
- Study/work focus environments
- Meditation and relaxation
- Background ambiance for content creation
- Tinnitus relief
- Sleep aid with nature sounds
- Digital wellness practices
