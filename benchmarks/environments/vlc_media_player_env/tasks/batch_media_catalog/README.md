# Batch Media Catalog Task

**Difficulty**: 🟡 Medium  
**Skills**: Media management, batch processing, documentation  
**Duration**: 90-120 seconds  
**Steps**: ~50

## Objective

Create a systematic catalog report documenting technical specifications of multiple video files, simulating a media librarian workflow.

## Real-World Scenario

You're a media librarian who received 4 video files from a faculty member. Before adding them to the institutional database, you need to create a catalog entry documenting each file's technical specifications.

## Task Description

Given 4 video files in `/home/ga/Videos/catalog_queue/`:
- `video_01.mp4` (1920x1080, ~45 seconds)
- `video_02.mkv` (1280x720, ~62 seconds)
- `video_03.avi` (854x480, ~38 seconds)
- `video_04.mp4` (1920x1080, ~51 seconds)

Create:
1. A catalog report at `/home/ga/Documents/media_catalog.txt` documenting each file
2. Snapshots from mid-point of each video in `/home/ga/Pictures/catalog_snapshots/`
